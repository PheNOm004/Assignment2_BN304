Idle Band — how far the temperature can drift from the target before the system activates. Wider = fewer cycles, more drift. Narrower = tighter control, more cycles. Shutoff Buffer — how many degrees before the exact target the devices switch off. Set to 0 to run all the way to the target. Positive values cut devices early and let thermal momentum coast to the target, reducing overshoot. Negative values (down to −2°C) allow deliberate overshoot past the target before cutting out — useful when thermal mass is large. Must stay within the idle band.
